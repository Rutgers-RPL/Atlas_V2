This is the JSON flows file to be used with the STM Cube Monitor. This tool is a failsafe in the chance that SD card, External Flash, and USB-CDC are uncooperative. 

Download Cube Monitor here:

https://www.st.com/en/development-tools/stm32cubemonitor.html

Once downloaded, click top right 3 bars, import, and select the flow JSON stored in this folder. 

Click "Deploy", "Dashboard", and "Start 

VERY IMPORTANT: if changes have been made to ATLAS, or there are otherwise any errors in initial setup, do the following:

Select the "myVariables" node
Edit the ELF file to be the one in the "binaries" folder from the repo
Confirm all changes in the GUI
Complete above steps
